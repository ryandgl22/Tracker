WINTER FITNESS TRACKER — iPHONE PWA PACKAGE

This folder is ready to be hosted as a static website. No cloud database is required.
Your logged entries remain in the browser/device storage. Use Export Full Backup regularly.

FILES TO HOST
- index.html
- manifest.webmanifest
- service-worker.js
- icon-192.png
- icon-512.png

IMPORTANT
For iPhone 'Add to Home Screen' + offline PWA behavior, these files need to be served over HTTPS.
Opening index.html directly from the Files app is not the same as installing a PWA.

AFTER HOSTING
1. Open the HTTPS web address in Safari on iPhone.
2. Tap Share.
3. Tap Add to Home Screen.
4. Tap Add.
5. Launch Winter Fitness Tracker from its Home Screen icon.

DATA TRANSFER
Phone: Backup & Transfer > Export full backup, save the JSON in Files/iCloud Drive/OneDrive.
Laptop: open the same hosted tracker, Backup & Transfer > Import backup.
Export from whichever device has the newest data before switching.
